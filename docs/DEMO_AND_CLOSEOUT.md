# 离线演示与交付边界

本仓是已公开的离线软件核心，不是交易系统。说明依据当前公开README、架构和隐私文档；本轮仅整理文档，没有重新运行测试、生成界面或验证投资效果。

## 建议补充的演示

| 画面 | 输入 | 应展示的输出 |
|---|---|---|
| 日频研究流程 | README中的虚构CSV、确定性合成价格 | 研究标签与依据、风险检查、待确认/批准/拒绝状态 |
| 周频研究池调整 | 合成候选表 | 人工批准前后的研究池状态；不是实际买入 |
| 历史与审计 | 同一合成任务的保存记录 | 恢复过程和审计轨迹；不展示真实账户或金额 |

可先做3–4张带说明截图，再录一段60–90秒操作流程。当前仓库未附实际录屏，不用示意图冒充已经运行的界面。人工确认不能绕过硬风险限制；月度主题仍是只读研究。

## 怎样算软件演示交付完成

准备可复现的合成配置、记录软件版本与环境、保存操作路径和预期状态，并提供一次对应运行记录。验证流程可运行与验证投资有效性分开：合成数据没有实际收益意义，前向方向账本也不模拟真实订单。

公开核心不包含OCR、实时行情、PDF下载、外部模型调用和API密钥配置。这些功能不进入本仓的演示待办，也不从其他私有项目复制样例或截图。
